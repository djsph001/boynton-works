# Boynton Works

Local community service directory for Boynton Beach, Florida.

Find someone local. Offer what you do.

## Stack

- Astro 6
- Static build (no database, no accounts, no payments)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Not yet deployed. Domain `boyntonbeach.online` is parked at Namecheap.
